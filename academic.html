Year 1 · programming and logic

Programming and digital logic

For the programming assignment I built a console toolkit that handles binary operations and parity checking, it also converts signed 8-bit numbers.

Digital electronic toolkit

The toolkit handles base and ASCII conversion, parity checks and truth tables, together with logic-device outputs and signed-binary values.

Logic-gate study

The truth-table rules of each Boolean gate are translated into program logic.

Programming structure

The submitted flow diagrams record how input is validated and how a function is selected, along with the repeat-control paths.

Year 2 · microcontrollers and control

Microcontrollers and embedded control

The three-floor elevator project handles floor calls and direction control, the same controller also drives the display, emergency handling and door coordination.

Microcontroller assignment

Three-floor elevator controller

The elevator is modelled on an 8051. Calls and floor indication are handled by the microcontroller, an L293D sets the motor direction when an emergency interrupt and a buzzer cover the emergency case. The design also includes reactivation, idle power saving and coordination with the door controller.

Finite-state digital-system design

The work includes a state table and K-map, a D flip-flop module, a clock divider and the Quartus schematic.

Embedded controller logic

Microcontroller routines process the calls and set the motor direction, the same routines also handle alarms and floor indication.

Sequential-system practice

Each state transition is checked against both the hardware and the software evidence.

Year 3 · ASIC and digital hardware

ASIC and digital hardware

The ASIC work starts from Boolean construction and ends with an 8-bit arithmetic design.

ASIC assignment

8-bit digital ALU building blocks

The design is written in gate-level Verilog. It consists of an 8-bit ripple adder, a NOR-only XNOR block and the overflow or carry indication, and each block is checked with its testbench evidence.

Hysteretic ON/OFF controller

Op-amp summing, inverter and comparator stages set two switching thresholds near the setpoint, hence the output will not toggle repeatedly when the input hovers near it.

CMOS and digital logic

Laboratory and design work on CMOS device behaviour and on how logic is implemented with it.

Process-control study

Control concepts were studied together with practical circuit construction, and the response of each circuit was then interpreted.

Year 4 · DSP, embedded systems and integration

DSP, embedded systems and the FYP

In the DSP laboratory the original signal is compared with the FIR-filtered output, in both the time domain and the frequency domain. In the same year I built the Smart Helmet dashboard and started my final-year EEG-BCI project.

Digital signal processing

FIR filters are designed and their response is analysed with time-domain and frequency-domain graphs.

Smart Helmet dashboard

A Python dashboard reads the ESP32 serial data. It shows the environmental values, inertial data and impact alerts, together with the connection state.

EEG-BCI final-year project

P300 decoding with vision-guided target selection, the selected target is then prepared for the robotic arm. Open the FYP page.
